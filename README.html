Feline Finances

A virtual cat ownership game — adopt a cat, manage five care stats, earn money through chores, and spend it on food, toys, grooming, and vet care.

At a Glance
  • Choose cat type, name, and personality at the start
  • Keep hunger, happiness, energy, cleanliness, and health above zero
  • Earn money via chore minigames on the Taskboard
  • Spend on items from Whiskermart or pay for vet visits
  • Neglect any stat to zero and the run ends

Main Features

Care Loop
  • Hunger, happiness, energy, cleanliness, and health bars
  • Mood changes based on current condition
  • If any stat reaches zero, the pet dies and the run ends
Money Loop
  • Whiskermart sells care items
  • Total earned and total spent are always visible
  • Expense categories track food, toys, grooming, and vet care
Extra Features
  • Care report with stats, spending, chores, and badges
  • Achievements and savings goal
  • Delete Save button with confirmation

Code Quality

Comments & Common Conventions
  • Every function has a name describing its purpose
  • Names reflect intent — e.g., update_stats, apply_item, load_save
  • Consistent indentation and formatting across all files
Modular Structure
  • 7 files across 4 packages: core, engine, gameplay, interface
  • Each file has one responsibility — models, storage, UI, assets, game loop
  • No large monolithic blocks — logic is broken into focused functions

User Experience

Clear Instructions
  • Setup screen guides through each customization step
  • All buttons are labeled with visible text and icons
  • Stat bars are always visible on the main screen
Navigation
  • Dedicated overlays: Store, Vet, Taskboard, Report, Help
  • Interactive Help menu accessible at any point in the game
  • No spelling errors or navigation dead-ends anywhere in the UI
Input Validation
  • Cat name is length-limited during the setup screen
  • Menu actions only accept valid choices
  • Save file is validated structurally and logically before loading

Functionality

Addresses the Prompt
  • Topic: the real cost and responsibility of pet ownership
  • Every care action has a direct financial consequence
  • Correlation explained on the setup screen and in the README
Report Output
  • Report overlay: mood, survival time, chores done, achievements
  • Spending breakdown by category — food, toys, grooming, vet
  • Live HUD shows current stats, inventory, earned, and spent totals
Data Storage
  • Each variable has one clear purpose and correct data type
  • Lists and dicts store inventory, achievements, and spending history
  • All game state is saved to and loaded from a JSON file
